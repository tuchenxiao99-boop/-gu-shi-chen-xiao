## 1. 建立有效成绩表

原始数据共有 **76 行 × 11 列**。其中有 4 名学生语文、数学、英语均为 0。

目前无法确认这些 0 分代表真实成绩、缺考还是尚未录入，所以本次分析先暂时排除，同时保留原始 `df` 不变。

```python
valid_df = df[
    ~(
        (df["语文"] == 0)
        & (df["数学"] == 0)
        & (df["英语"] == 0)
    )
]
```

```python
valid_df.shape
```

结果：

```text
(72, 11)
```

> **76 条原始记录 − 4 条三科全 0 记录 = 72 条暂定有效记录**

这段代码的逻辑：

| 代码 | 含义 |
| --- | --- |
| `(条件一) & (条件二)` | 多个条件同时满足 |
| `~(条件)` | 把条件结果取反 |
| `valid_df = ...` | 把筛选结果保存为新表 |

## 2. 三科基础统计

### 核心代码

```python
valid_df["语文"].mean()
valid_df["语文"].count()

valid_df["数学"].mean()
valid_df["数学"].count()

valid_df["英语"].mean()
valid_df["英语"].count()
```

### 统计结果

| 科目 | 平均分 | 有效人数 |
| :---: | ---: | ---: |
| 语文 | 78.85 | 71 |
| 数学 | 42.60 | 69 |
| 英语 | 40.10 | 69 |

三科满分均为 150 分，可以在同一量尺下进行初步比较。

但要注意：

- `valid_df` 有 72 行，不等于每科都有 72 个有效成绩；
- `mean()` 默认跳过 `NaN`；
- `count()` 只统计非缺失值；
- 缺失成绩不能直接当作 0 分。

报告时可以写：

> 均分按各科有效成绩计算，缺失记录不计入分母。

## 3. 数学分数段分析

### 先理解条件计数

统计数学 0—30 分人数：

```python
((valid_df["数学"] >= 0) & (valid_df["数学"] < 30)).sum()
```

它的运行过程是：

```text
逐行判断
→ 得到 True / False
→ sum() 把 True 当作 1
→ 得到人数
```

### 再用 `pd.cut()` 一次完成分组

```python
math_group = pd.cut(
    valid_df["数学"],
    bins=[0, 30, 60, 90, 120, 150],
    include_lowest=True
)

math_group.value_counts()
```

| 数学分数段 | 人数 |
| :---: | ---: |
| 0—30 | 22 |
| 30—60 | 30 |
| 60—90 | 17 |
| 90—120 | 0 |
| 120—150 | 0 |

**数据现象：** 69 个有效数学成绩中，52 人位于 60 分及以下，90 分以上暂未出现。

**谨慎表述：**

> 本次数学成绩整体偏低，学生主要集中在中低分数段。

仅凭一次分班成绩，还不能确定原因是长期基础薄弱、试卷难度，还是某些知识模块失分。

## 4. 英语学情分析

### 第一次分组：30 分一档

```python
english_group = pd.cut(
    valid_df["英语"],
    bins=[0, 30, 60, 90, 120, 150],
    include_lowest=True
)

english_group.value_counts()
```

| 英语分数段 | 人数 |
| :---: | ---: |
| 0—30 | 17 |
| 30—60 | 45 |
| 60—90 | 7 |
| 90—120 | 0 |
| 120—150 | 0 |

69 个有效英语成绩中，62 人位于 60 分及以下，约占 **89.9%**。

但是 30—60 分这一档挤了 45 人，分组太粗，看不出学生到底集中在 30 多分、40 多分还是 50 多分。

> **分组粒度要根据数据分布和分析目的调整。**

### 检查最高分

```python
valid_df["英语"].max()
```

```text
75.6
```

当前最高分没有触及 150 分边界，可以安全使用左闭右开的 10 分区间。

### 第二次分组：10 分一档

```python
english_10_group = pd.cut(
    valid_df["英语"],
    bins=list(range(0, 151, 10)),
    right=False
)

english_10_group.value_counts()
```

`right=False` 表示使用左闭右开区间：

```text
[0, 10)　[10, 20)　[20, 30)　……
```

| 20—30 | 13 |
| 30—40 | 21 |
| 40—50 | 16 |
| 50—60 | 8 |

## 5. 从数据到教学判断

学情分析可以套用一个简单结构：

> **现象 → 判断 → 行动**

**现象**

> 本班英语有效成绩 69 人，平均分 40.10 分。30—50 分共有 37 人，约占 53.6%，80 分以上暂未出现。

**判断**

> 本次英语成绩整体集中在中低分区间，中间层人数较多，高分段人数较少。

**初步行动**

> 后续可优先检查基础词汇、句型和阅读基本能力的掌握情况，同时关注 30—50 分学生的提升空间。

**证据边界**

> 以上判断只基于一次分班成绩。后续还需要结合题型得分、平时成绩和连续考试趋势进行验证。

一句话记住：

> **描述数据与解释原因要分开，结论不能超过证据。**

## 6. 新知识速查

| 写法 | 用途 |
| --- | --- |
| `.mean()` | 计算平均值，默认跳过 `NaN` |
| `.count()` | 统计非缺失值数量 |
| `.sum()` | 数值求和；也可统计布尔结果中的 `True` |
| `pd.cut()` | 把连续数值划分到不同区间 |
| `.value_counts()` | 统计每种值出现的次数 |
| `.max()` | 查找最大值 |
| `list(range(...))` | 批量生成等距边界 |
| `right=False` | 使用左闭右开区间 |
| `include_lowest=True` | 把最低边界包含进第一组 |

## 7. 今日易错点

| 易错写法 | 正确理解 |
| --- | --- |
| `df.valid["英语"]` | 变量名是 `valid_df["英语"]` |
| `[list(range(...))]` | `list(range(...))` 本身已经是列表 |
| `df.["数学"]` | `df` 后直接接方括号，不加点号 |
| `=` 和 `==` 混淆 | `=` 是赋值，`==` 是比较 |
| `,` 和 `.` 混淆 | `,` 分隔参数，`.` 调用对象功能 |
| 使用中文标点 | Python 代码使用英文半角 `() , ~` |
