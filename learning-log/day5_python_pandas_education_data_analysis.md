## 二、建立暂定有效成绩表 `valid_df`

### 1. 为什么不能直接使用全部记录

原始数据共有：

```text
76 行 × 11 列
```

检查时发现 4 名学生的语文、数学、英语均为 0。仅凭当前表格，不能确认这些 0 分代表实际考试成绩、缺考还是尚未录入。因此，本次分析暂时排除三科全为 0 的记录，同时保留原始 `df` 不变。

### 2. 筛选代码

```python
valid_df = df[
    ~(
        (df["语文"] == 0)
        & (df["数学"] == 0)
        & (df["英语"] == 0)
    )
]
```

这段代码可以分成三层理解：

```text
(...) & (...) & (...)  → 找到“三科全为 0”
~                      → 条件取反，保留“不是三科全为 0”
valid_df =             → 把结果保存成新的分析表
```

确认结果：

```python
valid_df.shape
```

```text
(72, 11)
```

重要原则：

> `valid_df` 是根据当前分析规则建立的新表，不会修改原始 `df`。如果以后确认 0 分的真实含义，可以重新调整规则。

## 三、均分与有效人数

### 1. 基本写法

```python
valid_df["语文"].mean()
valid_df["语文"].count()

valid_df["数学"].mean()
valid_df["数学"].count()

valid_df["英语"].mean()
valid_df["英语"].count()
```

### 2. 统计结果

| 科目 | 平均分 | 有效人数 |
| --- | ---: | ---: |
| 语文 | 78.85 | 71 |
| 数学 | 42.60 | 69 |
| 英语 | 40.10 | 69 |

三科满分均为 150 分，因此可以在相同量尺下进行初步比较。但各科缺失数量不同，报告均分时必须同时注明有效人数。

### 3. `mean()` 与 `count()` 的统计口径

- `mean()` 默认跳过 `NaN`，不会把缺失成绩当作 0 分；
- `count()` 只统计非缺失值；
- `valid_df` 有 72 行，不代表每一科都有 72 个有效成绩。

正式报告可以写：

> 均分按各科有效成绩计算，缺失记录不计入分母。

### 4. `count()` 与 `sum()` 的区别

直接统计非缺失成绩：

```python
valid_df["语文"].count()
```

也可以先判断非空，再统计 `True`：

```python
valid_df["语文"].notna().sum()
```

可先记为：

```text
count()  → 直接数非空值
sum()    → 数值求和；布尔结果中 True 按 1 计数
```

## 四、从条件计数理解分数段

在使用新函数前，先用已有的布尔条件统计数学 0—30 分人数：

```python
((valid_df["数学"] >= 0) & (valid_df["数学"] < 30)).sum()
```

运行过程是：

```text
逐行判断是否同时满足两个条件
→ 得到一串 True / False
→ sum() 把 True 当作 1
→ 得到该分数段人数
```

数学 30—60 分可以写成：

```python
((valid_df["数学"] >= 30) & (valid_df["数学"] < 60)).sum()
```

这种方式有助于理解分段逻辑，但如果区间很多，逐段书写会产生大量重复代码，因此引入 `pd.cut()`。

## 五、使用 `pd.cut()` 与 `value_counts()`

### 1. 数学成绩分段

```python
math_group = pd.cut(
    valid_df["数学"],
    bins=[0, 30, 60, 90, 120, 150],
    include_lowest=True
)
```

这里 6 个边界形成 5 个区间：

```text
0—30
30—60
60—90
90—120
120—150
```

查看每名学生对应的分数段标签：

```python
math_group.head()
```

统计各段人数：

```python
math_group.value_counts()
```

结果：

| 数学分数段 | 人数 |
| --- | ---: |
| 0—30 | 22 |
| 30—60 | 30 |
| 60—90 | 17 |
| 90—120 | 0 |
| 120—150 | 0 |

在 69 个有效数学成绩中，52 人位于 60 分及以下，90 分以上暂未出现。

更稳妥的描述是：

> 本次数学成绩整体偏低，学生主要集中在中低分数段，90 分以上暂未出现。

这里只能描述本次成绩分布。仅凭一次分班成绩，还不能确定原因是长期基础薄弱、试卷难度还是某些知识模块失分。

### 2. `include_lowest=True`

`pd.cut()` 默认生成右闭区间，例如：

```text
(0, 30]
```

这可能漏掉恰好等于 0 的成绩。加入：

```python
include_lowest=True
```

可以让最低边界 0 被第一个区间包含。

## 六、英语学情分析

### 1. 先使用较粗的 30 分分段

```python
english_group = pd.cut(
    valid_df["英语"],
    bins=[0, 30, 60, 90, 120, 150],
    include_lowest=True
)

english_group.value_counts()
```

结果：

| 英语分数段 | 人数 |
| --- | ---: |
| 0—30 | 17 |
| 30—60 | 45 |
| 60—90 | 7 |
| 90—120 | 0 |
| 120—150 | 0 |

69 个有效英语成绩中，有 62 人处于 60 分及以下，约占 89.9%。但 45 人都挤在 30—60 这一档，无法继续看出 30 多分、40 多分和 50 多分学生之间的结构。

这说明：

> 分组粒度要根据数据分布和分析目的调整。

### 2. 检查最高分与边界

英语满分为 150 分。如果使用左闭右开区间 `[0, 10)`、`[10, 20)`，恰好 150 分会落在最后一个区间之外。因此切分前先检查最高分：

```python
valid_df["英语"].max()
```

结果：

```text
75.6
```

当前数据没有触及 150 分边界，可以按 10 分一档进行切分。

### 3. 改为 10 分一档

```python
english_10_group = pd.cut(
    valid_df["英语"],
    bins=list(range(0, 151, 10)),
    right=False
)

english_10_group.value_counts()
```

`list(range(0, 151, 10))` 生成 16 个边界：

```text
0, 10, 20, ... , 140, 150
```

15 个分数段需要 16 个边界。`right=False` 表示使用左闭右开区间：

```text
[0, 10)
[10, 20)
[20, 30)
...
```

这样 10 分会进入 `[10, 20)`，分段规则更统一。

### 4. 英语 10 分段结果

| 英语分数段 | 人数 |
| --- | ---: |
| 0—10 | 2 |
| 10—20 | 2 |
| 20—30 | 13 |
| 30—40 | 21 |
| 40—50 | 16 |
| 50—60 | 8 |
| 60—70 | 5 |
| 70—80 | 2 |
| 80—150 | 0 |

关键现象：

- 30—40 分有 21 人；
- 40—50 分有 16 人；
- 30—50 分合计 37 人，占 69 个有效英语成绩的约 53.6%；
- 60 分以上共 7 人；
- 80 分以上暂未出现。

因此，本次英语成绩不是由少数低分记录单独拉低，而是整体分布集中在中低分区域。

## 七、从数据到教学判断

学情分析可以使用一个固定结构：

```text
现象（数据）
→ 判断（说明什么）
→ 教学行动（准备怎么做）
```

### 1. 现象

> 本班英语有效成绩 69 人，平均分 40.10 分；成绩主要集中在 30—50 分区间，其中 30—40 分 21 人、40—50 分 16 人，80 分以上暂未出现。

### 2. 谨慎判断

> 本次英语成绩整体处于中低分区间，中间层人数较集中，高分段人数较少。

### 3. 初步教学行动

> 后续教学可优先检查基础词汇、句型和阅读基本能力的掌握情况，并关注 30—50 分中间层学生的提升空间。

合并成一段报告语言：

> 根据本次分班成绩分析，本班英语有效成绩 69 人，平均分 40.10 分，学生主要集中在 30—50 分区间，高分段人数较少。当前可优先核查基础词汇、句型和阅读基本能力的掌握情况，同时关注中间层学生的提升。以上判断基于单次分班成绩，后续仍需结合题型得分、平时成绩和连续考试趋势进行验证。

这里最重要的原则是：

> 描述数据与解释原因要分开；结论强度不能超过证据强度。

## 八、今天强化的 Python 语法

### 1. `=` 与 `==`

```text
=   赋值，或给函数参数指定值
==  比较两边是否相等
```

示例：

```python
english_group = pd.cut(...)  # 保存结果
df["英语"] == 0             # 判断是否等于 0
```

### 2. `,` 与 `.`

```text
,  分隔不同的参数或元素
.  调用某个对象所属的功能或属性
```

示例：

```python
pd.cut(A, B, C)
```

- `pd.cut` 中的点号表示从 pandas 中调用 `cut`；
- `A, B, C` 中的逗号表示三个不同参数。

### 3. `&` 与 `~`

```text
&  多个条件同时满足
~  对布尔条件取反
```

多个 pandas 条件要分别加圆括号：

```python
(条件一) & (条件二)
```

### 4. 列表不要重复嵌套

```python
list(range(0, 151, 10))
```

本身已经是一个列表，不要再写成：

```python
[list(range(0, 151, 10))]
```

后者会变成“列表里再装一个列表”，不符合 `pd.cut()` 对一维边界序列的要求。

### 5. 使用英文半角标点

Python 代码应使用：

```text
( )  ,  ~
```

不要混入中文全角括号、逗号或波浪号。
