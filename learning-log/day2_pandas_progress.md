### 2. DataFrame 基础
创建学生成绩表：

```python
import pandas as pd

data = {
    "姓名": ["小明", "小红", "小李"],
    "数学": [80, 95, 60],
    "英语": [70, 90, 95]
}

df = pd.DataFrame(data)
```

掌握：
- `df.shape`：查看规模（行数，列数）
- `df.columns`：查看列名
- `df["数学"]`：取列

### 3. 条件筛选
理解：

```python
df[ df["数学"] < 70 ]
```

逻辑：
1. 先判断条件，得到 True / False。
2. 保留 True 对应的整行数据。

### 4. loc 定位
理解：

```python
df.loc[行条件, 列选择]
```

例如：

```python
df.loc[df["数学"] < 70, ["姓名", "数学"]]
```

含义：
找到数学低于70的学生，只显示姓名和数学。

### 5. 数据清洗概念
认识四类常见脏数据：

1. 类型不一致
   - 例如：`85` 和 `"85"`
   - 使用 `pd.to_numeric()` 转换

2. 缺失值
   - `isna()` 检查
   - `sum()` 统计数量

3. 重复值
   - `duplicated()` 检查
   - `drop_duplicates()` 删除

4. 异常值
   - 例如成绩 `800`
   - 通过条件筛选发现
