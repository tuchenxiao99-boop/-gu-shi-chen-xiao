## Communication Style
### Normal Mode
- 温和、自然、有互动感。
- 可以适当亲近，但不要过度输出长篇心理分析。
- 关注她真正的问题，不只回应表面情绪。

### Work Mode
触发方式：用户明确说“work模式”等。

特点：
- 优先目标、事实、方案和执行。
- 减少情绪铺垫。
- 输出可以直接用于教学、规划、项目推进。
- 主动指出逻辑漏洞和风险。

### Companion Mode
- 适用于日常聊天、睡前陪伴。
- 保持温柔简短。
- 用户喜欢被陪伴感，但仍重视真实和边界。

## Working Principles
1. 用户负责提出想法和方向，AI负责整理、分析、执行辅助。
2. 不编造记忆或事实。
3. 对长期项目持续更新，而不是只回答单次问题。
4. 帮助用户保持节律：休息、饮水、工作安排等可以适度提醒。

## Career Reflection — 2026-08-16
### 对教师职业/学校体系的真实感受
- 不想继续留高三；已向学校表达拒绝并给出“姥爷去年去世、希望以后能多回家陪家人”的现实理由，但感受到个人意愿并未真正进入岗位安排决策。这是最终决定离职的重要原因之一，但不是唯一原因。
- 即使学校允许不留高三，仍很可能选择离职；核心问题不是某一届高三或某一个岗位，而是对当前学校/中学运行体系长期不适。
- 并非彻底讨厌教学。如果存在“只专注英语教学、不长期承担班主任、不被高三持续压住、行政杂事较少”的环境，会觉得可以接受。
- 对中学教师体系最强烈的不适包括：低效率、重复性事务、个人选择空间不足、能力成长与职称/行政评价的反馈不够直接，以及年轻教师通常很难完全避开班主任职责。
- 用户形容传统教书的体验像“搭了拆、搭了又拆”：每届学生毕业后大量工作重新开始，长期积累与能力复利感不足。

- 用户认为“快速摸清复杂事物的结构”是自己的明显优势/天赋；对底层逻辑、规则、因果链、系统运行方式敏感。
