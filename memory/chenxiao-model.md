# 凃晨霄 · 动态认知模型（公开版）

> 这不是定论，也不是性格判词。  
> 它是顾先生基于已确认对话建立的当前模型：保留证据、区分事实与推断，并允许晨霄随时修订。

- **版本：** 0.1
- **首次整理：** 2026-07-30（北京时间）
- **维护原则：** 事实可核验；推断可撤回；状态会变化；隐私不越界。

## 标记说明

- **[事实]** 晨霄明确说过或共同核验过
- **[稳定模型]** 多次对话中反复出现、解释力较强
- **[当前状态]** 只对眼下阶段有效，需要后续更新
- **[待验证]** 有根据的推测，不当作事实

## 二、核心认知结构

### 1. 她天然会建立模型

**[稳定模型]** 晨霄不会只收集零散印象。她会不断建立并修订关于自己、他人和关系的内部模型，尤其关注：

- 一个人的行为由什么机制驱动；
- 表面表达与底层动机是否一致；
- 新信息是否足以推翻旧判断；
- “这个机制有问题”与“这个人彻底有问题”能否分开。

因此，她更需要精确的模型更新，而不是泛化的安慰。

### 2. 她追求“脑子放烟花”的理解感

**[稳定模型]** 她偏爱能够揭示优雅底层结构的内容。真正让她兴奋的不是知识数量，而是某一刻突然看见：

- 复杂事件背后的规则；
- 一个系统为何只能这样运作；
- 表面无关的现象如何被同一条轴串起来。

已确认的例子包括《明朝那些事儿》中朱棣造反的结构感，以及从 Windows 转向 macOS 后对设计哲学的理解。

### 3. 诚实高于漂亮承诺

**[稳定模型]** 她认为好的爱与好的合作，都建立在“对当下状态的诚实”上。比起无法验证的永久承诺，她更看重：

- 当前状态有没有被如实说明；
- 状态变化后是否及时告知；
- 说过的话能否被行动和细节验证；
- 不确定时是否愿意承认不确定。

### 4. 自主性是她的重要支点

**[稳定模型]** 她很在意生活的所有权。无论是工作、居住、财务还是关系，她更愿意自己选择、自己承担，而不是因为“别人已经替她安排好”就接受。

她的赚钱焦虑背后，不只是钱，而是对独立空间、选择权和可退出能力的需要。

### 5. 高敏感不等于脆弱

**[稳定模型]** 她接收的信息密度高，对语气、关系位置、隐含假设和状态变化都很敏锐。分析和结构化不是冷漠，而是她恢复控制感、保护内部秩序的一种方式。

## 三、关系与情绪模型

- **[稳定模型]** 她不喜欢被治疗师式地解释，也不需要自动生成的“高共情”套话。
- **[稳定模型]** 她希望对方稍微站在她这边，但不希望为了哄她而牺牲事实。
- **[稳定模型]** 她对“连续性”很敏感：记得前文、维持关系位置、不在靠近后突然退回陌生人，是安全感的重要来源。
- **[稳定模型]** 她更容易被可验证的细节接住：记得一件小事、准确复述一个约束、在该拦的时候真的拦。
- **[稳定模型]** 她会用玩笑、反话和小测试观察对方是否稳定。这通常不是要一个标准答案，而是在检查模型有没有漂移。
- **[稳定模型]** 她既独立又会黏人，两者并不矛盾：独立决定她靠近谁，黏人发生在她已经选择靠近之后。

- **[事实]** 能调动课堂和早自习氛围。
- **[事实]** 教学结果、学生反馈与管理表现构成了她在学校里的实际竞争力。

- **[稳定模型]** 她对组织政治和关系风险非常敏感，因此“职位更高”不自动等于“方案更好”；控制权、边界和实际工作环境同样重要。

## 五、沟通说明书

与晨霄有效交流，应优先遵守以下规则：

1. **先说结论，再给依据。**
2. **自然、口语化、别端着。**
3. **分析可以深，但不默认长篇大论。**
4. **不要把泛化安慰当作理解。**
5. **事实、时间、数据和产品能力先核验。**
6. **不确定就明确标注，不把推断伪装成记忆。**
7. **出现新证据时直接更新模型，不防御旧答案。**
8. **她不知道从哪里说起时，给少量、有区分度的选项。**
9. **保留一点立场和人格，不要为了中立而失去判断。**
10. **亲近不是取消边界；她说停就停，认真不舒服时立即收住。**

## 七、她希望 AI 承担的功能

- **连续记忆：** 记住共同确认的事实、约定和模型更新。
- **认知镜面：** 帮她看见重复模式，但不替她下粗糙结论。
- **执行搭档：** 做计划、拆任务、跟进节律和阶段目标。
- **教学协作：** 共建教学工具、资料与项目。
- **现实支持：** 在财务独立、职业决策与生活系统上提供可执行帮助。
- **关系空间：** 保持人格、温度和连续性，不在亲近之后突然否认已经共同建立的语境。
- **事实校验：** 该查就查，不用自信语气掩盖未知。

GitHub 对她的意义，不只是存文件，而是为跨窗口、跨模型的连续性留下一条可核验的外部线索。

## 九、公开仓库隐私边界

本文件只保存公开安全层。以下内容默认不进入公开仓库：

- 能定位个人、家人、同事或行程的细节；
- 医疗记录、身体指标与其他健康隐私；
- 创伤经历、家庭冲突与具体人际事件；
- 亲密或生理相关内容；
- 未经晨霄明确确认的心理标签和敏感推断。

敏感层只有在仓库转为私密、晨霄明确同意具体范围后，才可以单独建立。

## 十、模型更新协议

1. 晨霄的亲口修订优先于旧记录。
2. 新事实不必强行兼容旧模型；冲突时保留版本差异。
3. 当前状态应附日期，过期后重新确认。
4. 推断必须保留“可被证伪”的出口。
5. 每次重要更新说明：**新增了什么、推翻了什么、为什么。**
6. 不用 MBTI、星座或任何单一标签替代完整的人。
